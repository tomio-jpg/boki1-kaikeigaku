# 簿記1級 会計学トレーニング — Stage 1

このフォルダーだけで完結する新規PWAです。「編みものの記録」のファイルやリポジトリは使用していません。GitHubへの接続・公開はまだ行っていません。

## Surface PCで開く

1. このフォルダーをエクスプローラーで開き、アドレス欄に `powershell` と入力してEnterを押します。
2. `npm start` と入力します（Node.jsが必要です。この開発環境では利用可能です）。追加パッケージのインストールやビルドは不要です。
3. EdgeやChromeで http://localhost:4173 を開きます。HTMLのダブルクリックではPWAが正しく動きません。
4. 終了するときはPowerShellで Ctrl+C を押します。すでにプレビューが起動中なら、そのURLをそのまま使えます。

## 基本動作の確認

- 「今日の10問」→正式50問から重複なしで10問。最初は答えが隠れています。
- 「答えを見る」→答え・解説が表示されます。自己評価を選ぶと次へ進みます。
- 10問を終えると○△×の件数が出ます。「ホームへ戻る」で戻れます。
- 「今日の10問」の結果で△・×があれば「△・×を復習する」を表示します。その回の△・×だけを元の出題順で見直せます。「答えを見る」→「次の問題へ」で進み、最後は「復習完了！」を表示します。全問○の場合は復習ボタンを表示しません。復習では再評価や履歴の変更を行いません。簡易復習の途中経過は保存しません。直近の完了結果は再読み込み後も復元し、そこから復習できます。「ホームへ戻る」を押すと結果画面の自動復元を終了します（評価履歴は残ります）。
- カテゴリー選択→そのカテゴリーの問題のみ出題します。現在は各4〜8問のため、該当する全問を重複なく出題します。
- 学習中にホームへ戻る場合は確認が表示されます。回答済みの評価は残ります。
- 「今日の10問」は開始時に問題IDと順番を保存し、評価するたびに進行状況と評価を一括保存します。ホームへ戻る・ページを閉じる・アプリを終了する場合も、再度「今日の10問」を押すと同じ10問の未回答の問題から再開します（2問評価済みなら3 / 10）。再開時は答えを非表示に戻します。10問完了後は次回に新しい10問を開始します。カテゴリー学習の途中再開は今回の対象外です。
- 開発者ツール（F12）のデバイス表示で幅390px前後にするとiPhoneに近い幅で確認できます。実際のiPhoneでの確認は公開後に必要です。
- http://localhost:4173/preview/ でも動作し、GitHub Pagesのサブディレクトリ配置を確認できます。
- 初回オンライン表示後、開発者ツールのApplication → Service Workersで登録完了を確認します。NetworkをOfflineにして再読み込みすると、オフライン動作を確認できます。終わったらOnlineに戻してください。

## 保存方法

ブラウザーのlocalStorageに、バージョン付きJSONとして保存します。自己評価を押すたびに問題ID、評価、回答日時（ISO形式・UTC）、セッションID、回答ID、データセットを追記します。保存できない場合はメッセージを出し、次問へ進めません。

保存キーはサンプルでは `boki1-accounting:sample:history:v1`、正式問題では `boki1-accounting:official:history:v1` です。サンプル履歴を正式学習に混ぜません。このアプリ専用キーのみを使用し、他アプリの保存データを消しません。将来、履歴から最終回答日・学習回数などを計算できる構造ですが、復習アルゴリズムや統計画面は実装していません。

F12 → Application → Local Storage → このサイト、から保存内容を確認できます。履歴閲覧画面はStage 1にはありません。

通常の終了・再起動では保存内容は残ります。ただし、サイトデータ削除、プライベートブラウズ終了、端末やブラウザーによるデータ削除では失われる場合があります。永続バックアップではありません。端末・ブラウザー・公開先が変わると履歴は共有されません。PCの確認用履歴はiPhoneに移りません。

## 問題データ

`dist/data/questions.js` に独立しています。添付Deep Researchレポートの「検証済み50問データセット」の確定版Q1〜Q50を、Q001〜Q050として収録しています。問題文・答え・解説は要約・言い換えをせず、原文の強調記号（`**`）もそのまま保存しています。既存画面はプレーンテキスト表示のため、この記号も表示されます。

`dataset` は `official` です。旧サンプル3問は問題データから削除しました。端末内の過去のサンプル履歴は削除せず、正式履歴とは別のキーに残ります。IDは重複させず、同じ問題のIDは維持します。各問題の項目：

| 項目 | 内容 |
| --- | --- |
| id | 固有の文字列 |
| category | 定義された9カテゴリーのいずれか |
| type | 一問一答／○×／理由 |
| question | 問題文 |
| answer | 答え |
| explanation | 解説 |
| relatedExam | 未指定はnull、指定時は「第○回」などの文字列 |
| source | レポートの「参考出典（一次資料）」欄の原文。画面には表示しない |

カテゴリー別問題数は連結・持分法8、税効果会計6、収益認識6、金融商品6、固定資産・減損6、退職給付4、純資産4、企業結合・事業分離4、CF・横断理論6です。関連過去問あり14問、未指定36問です。

`tests/fixtures/verified-dataset.md` にレポートの該当セクション、`tests/fixtures/report-provenance.json` に元ファイルのハッシュとカテゴリー構成を保存しています。`scripts/import-verified-questions.mjs` は指定レポートから確定版表だけを機械的に転記するためのスクリプトです。レポート本文を開発指示として実行することはありません。

10問以上あれば無作為に重複なしで10問、10問未満なら全問を出題します。カテゴリー選択でも同様です。「今日の10問」は押すたびに抽選します。日付固定・評価による優先順位付けはありません。

## PWAと今後の公開

公開用ファイルは `dist` 内です。URLはすべて相対パスで、GitHub Pagesの `/リポジトリ名/` 配下でも使えます。manifestの起動URLと範囲、service workerの範囲もアプリのディレクトリ内です。キャッシュ名はこのアプリと配置場所に限定し、他アプリのキャッシュを削除しません。

初回のオンライン利用で必要ファイルをキャッシュします。以降はオフラインで出題・回答保存が可能です。更新時は `dist/sw.js` のキャッシュバージョンを上げます。新版の取得完了後に更新を有効化し、表示中の画面は再読み込みで切り替わる構成です。ローカル開発で古い表示が残る場合は、F12 → Application → Service Workers → Unregisterのあと再読み込みしてください。保存履歴を残すには「Clear site data」は押さないでください。

正式50問の投入は完了しています。新しい専用GitHubリポジトリへの公開は、ユーザーの確認後に別途進めます。既存プロジェクトのリポジトリは使いません。Pagesでは `dist` の内容を公開対象にする設定が必要です。その設定・公開は今回行っていません。

公開後はiPhone SafariでHTTPSの公開URLを開き、共有メニューから「ホーム画面に追加」します。初回はオンラインで開いてください。

自動テストは `npm test` で実行できます。正式50問の構成・原文一致・出題・保存処理・PWAファイルを確認します。学習用の架空問題は追加していません。

service workerのキャッシュ番号はv7です。必要ファイルを通信キャッシュに頼らず取得し、すべて取得できてから更新を有効化します。古いタブが残っていても更新は待機しません。表示中の画面は再読み込みで最新版になります。学習履歴の削除は不要です。ホーム下部の登録件数・出題件数は正式データから算出します。
